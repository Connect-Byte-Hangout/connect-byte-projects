## 🛠️ Bill of Materials
To build this project, you will need the following components:

* **1x Light Sensor Module (LDR)**
* **1x Coin Cell Battery (3V):** Standard model, such as a CR2032.
* **1x LED:** To change the color, make sure to verify the correct resistor value.
* **1x Resistor:** Can range from 220Ω to 470Ω depending on the chosen LED color.
* **Jumper Wires:** For the connections, don't worry about matching the exact colors in the diagram. Just follow the standard practice: use darker wires for negative and lighter wires for positive.

## 🛠️ Lista de Materiais
Para montar este projeto, você precisará dos seguintes componentes:

* **1x Módulo Sensor de Luz (LDR)**
* **1x Bateria tipo moeda (3V):** Modelo padrão, como a CR2032.
* **1x LED:** Para trocar a cor, verificar o resistor correto.
* **1x Resistor :** Pode variar entre 220Ω até 470Ω dependendo da cor do LED escolhido.
* **Fios de conexão (Jumpers):** Para realizar as ligações não se apegue as cores do diagrama. Siga o padrão: fios mais escuros para negativo e mais claros para positivo.
