# Planner Interativo com LEDs

Um projeto prático de eletrônica onde as participantes constroem um rastreador de hábitos ou planner diário interativo dentro de um porta-retrato.

Este projeto foi desenvolvido durante um encontro da Connect Byte e introduz interação física e lógica básica de circuitos de forma criativa.

---

## 🎨 Visão Geral do Projeto

Neste projeto, as participantes utilizam um porta-retrato para criar um "quadro de missões" ou rastreador de hábitos visual. Cada tarefa está ligada a um interruptor físico e a uma saída (como um LED ou um motor de vibração).

Quando uma tarefa é concluída, virar a chave ativa o circuito, proporcionando um feedback visual e físico satisfatório de realização.

Este projeto foi pensado para ser modular, permitindo que as participantes escolham seu nível de complexidade:

**🌱 Nível 1 — Básico:** Um circuito simples usando chaves gangorra e LEDs. Concluir uma tarefa acende sua luz correspondente.

**⚡ Nível 2 — Intermediário:** Um circuito aprimorado com múltiplas chaves, LEDs e um motor vibratório. A "tarefa principal" aciona simultaneamente uma luz e uma vibração háptica quando concluída.

---

## 🧩 Como Vamos Integrar Arte e Eletrônica

Para garantir uma integração perfeita entre o design do planner e o hardware, este projeto apresenta conceitos fundamentais como:

1. *Eletrônica Básica:* Compreensão de Tensão, Corrente, GND e malhas de circuitos.
2. *Controle de Componentes:* Entender como os interruptores funcionam como comportas para a corrente e como os resistores protegem os circuitos.
3. *Circuitos em Paralelo:* Como criar caminhos independentes para que chaves diferentes controlem tarefas separadas, ou como uma única chave pode acionar dois elementos ao mesmo tempo (LED + Motor).
